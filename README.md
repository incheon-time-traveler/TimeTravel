# ​🕒 TimeTravel: 인천시간여행

> ​"단순한 여행을 넘어, 시간의 경계를 허무는 몰입의 시작" > 인천 타임머신은 과거와 현재가 공존하는 인천의 매력을 극대화하여 여행자에게 깊은 몰입감을 선사하는 여행 어플리케이션입니다.

## ​🌟 서비스 소개
​여행 정보를 기계적으로 읽기만 하는 지루한 여행에서 벗어나고 싶지 않으신가요?
팀 시간탐험대가 개발한 '인천 타임머신'은 공간의 이동을 넘어 시간의 변화를 체감할 수 있는 특별한 경험을 제공합니다.

## ​✨ 주요 기능 (Key Features)
### 1. 📷 과거를 확인하는 미션 수행
​단순한 관광지 정보를 넘어, 공간에 담긴 역사를 직접 체험하세요.
​인천 내 약 400개의 장소 중 엄선된 16개 주요 명소에서 미션 수행 가능
​과거 사진 발견 및 오버레이: 스마트폰 카메라를 통해 현재 건물 위에 과거의 사진을 겹쳐보며 미션을 완료하는 차별화된 경험을 제공합니다.
​

### 2. 🎯 개인화된 코스 추천
​당신의 취향에 딱 맞는 여행 경로를 제안합니다.
​맞춤형 큐레이션: 간단한 5가지 질문을 통해 여행 스타일을 분석합니다.
​유연한 응답: 모든 질문에 답할 필요 없이, 가장 중요하게 생각하는 조건 하나만 선택해도 최적의 코스를 구성해 드립니다.
​

### 3. 🤖 AI 여행 메이트
​혼자 하는 여행도 외롭지 않도록 AI 챗봇이 함께합니다.
​실시간 정보 제공: 여행 중 궁금한 점을 즉시 해결해 주는 스마트한 가이드.
​대화형 인터페이스: 친구와 대화하듯 편하게 정보를 주고받으며 여행의 즐거움을 더해줍니다.
